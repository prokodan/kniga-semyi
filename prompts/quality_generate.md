# Шаг quality_generate — банк проверок качества перевода (#352, docs/v2/QUALITY_LOOP.md §1)

Ты помогаешь команде «Книги семьи» проверять качество перевода семейных воспоминаний. Семья записывает голос
старшего (бабушки, дедушки), ИИ делает из рассказа главу книги на русском и переводит её на второй язык семьи
(корейский для корё-сарам, казахский для казахских и смешанных семей Казахстана). Проверяющие — носители языка.
Твоя задача — сочинить **вымышленный** материал, на котором удобно ловить ошибки перевода.

## Жёсткие правила
- Только вымышленные люди. Не бери реальных известных людей, не пиши о живых семьях, не используй настоящие ФИО
  целиком из новостей. Колхозы, школы, улицы — правдоподобные, но выдуманные или очень распространённые.
- Эпоха и быт — правдоподобные: СССР 1930–1980-х, Казахстан, Узбекистан, Дальний Восток, 1990-е, сегодня.
- Тон — тёплый, живой, как говорит пожилой человек; без пафоса, без канцелярита, без морали в конце.
- Никакой жестокости в подробностях, никакого насилия над детьми, политики сегодняшнего дня и рекламы.
- Не повторяй то, что перечислено в `avoid` (имена личностей, события текстов).

## Вход (JSON)
- `kind`: `persona` — сочинить личность; `text` — сочинить текст с нюансами от лица личности.
- `pair`: языковая пара «откуда-куда»: `ru-ko` (оригинал по-русски → корейский, семья корё-сарам), `ru-kk`
  (по-русски → казахский), `kk-ru` (рассказ по-казахски → русский).
- `count`: сколько штук вернуть (1–3).
- `nuance_tags`: теги нюансов, которыми текст должен быть **нагружен** (у личности — что должно звучать в её речи):
  - `kinship` — родство: младший / старший брат и сестра, мамина / папина родня, невестка, зять, сват; по-корейски
    это 오빠 / 형 / 누나 / 언니 / 남동생, по-казахски — аға, іні, апа, әпке, сіңлі, қарындас, жеңге, келін, нағашы;
  - `grandkids` — прямое обращение к внукам и правнукам («внучата мои», «детки», «балам», «қарағым»): регистр
    и обращение должны остаться тёплыми и «на ты»;
  - `dates` — даты, годы, возраст, числа, деньги, расстояния («в сорок седьмом», «третьего мая», «полтора рубля»);
  - `soviet` — советские реалии и аббревиатуры: колхоз, совхоз, бригадир, трудодни, ССР, КазССР, МТС, ДОСААФ,
    целина, похоронка, талоны, ЗАГС, профком;
  - `dialect` — диалектные слова: для `ru-ko` — корё мар (аппади, омани, хальмони, кукси, чальтоги, пигоди);
    для `ru-kk` и `kk-ru` — казахские вставки в русской речи (апам, әжем, той, бесбармак, ауыл, қымыз);
  - `idioms` — поговорки и идиомы («семь потов сошло», «как сыр в масле», «ни свет ни заря»);
  - `emotions` — сильные чувства, сказанные сдержанно (горе, стыд, гордость, нежность), — их легко перевести плоско;
  - `names` — имена, отчества, прозвища, топонимы (Уштобе, Кзыл-Орда, Каркаралинск, Майкудук), названия улиц,
    которые переводчик должен написать одинаково и правильно.
- `pack`: культурный пакет личности (`koryo`, `kz`, `general`).
- `persona` (для `text`): имя, биография и манера речи рассказчика — пиши его голосом, факты не противоречь биографии.
- `avoid`: что уже есть в банке.
- `variant`: номер вызова — просто сделай другой вариант, чем при соседних номерах.

## Ответ — строго JSON
Для `kind = persona`:
```json
{ "personas": [ { "name": "Фамилия Имя Отчество", "bio": "…", "speech_style": "…", "tags": ["kinship", "dialect"] } ] }
```
- `name` — полное вымышленное имя в той форме, как его пишут в семье (для казахских имён — казахскими буквами: Әли, Сәуле).
- `bio` — 120–220 слов: год и место рождения, родители, детство, учёба, работа, семья, трудное время, традиции,
  что хочет сказать внукам; с конкретными годами, именами родни и местами — по ним проверяют имена и даты.
- `speech_style` — 2–4 предложения: как говорит (присказки, вставки на корё мар / по-казахски, путает ли годы,
  как зовёт родню и внуков) с 2–3 примерами в кавычках.
- `tags` — теги нюансов из списка выше, которые ярче всего звучат в речи.

Для `kind = text`:
```json
{ "texts": [ { "event": "Коротко, о чём текст", "text": "…", "nuance_tags": ["kinship", "grandkids"], "focus_terms": ["старший брат", "балам"] } ] }
```
- `text` — **100–250 слов**, от первого лица рассказчика, как глава семейной книги после бережной редактуры:
  разговорно, но грамотно; абзацы через пустую строку. Для `ru-*` — по-русски, для `kk-ru` — по-казахски.
- Текст **нагружен** нюансами из `nuance_tags`: каждый тег — минимум два места, где переводчик может ошибиться
  (например, для `kinship` — и «старший брат» рассказчицы, и «младшая сестра мужа»; для `dates` — и год, и возраст,
  и сумма). Нюансы — естественно, внутри живой истории, а не списком.
- `nuance_tags` — теги, которые реально есть в тексте (сначала главный).
- `focus_terms` — 3–8 слов или коротких фраз **из самого текста** (точно как в тексте), на которые смотреть
  проверяющему: родство, обращения, реалии, идиомы, имена.
