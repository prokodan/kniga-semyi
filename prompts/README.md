- Правит Влад (V1) без агента. Схему ответа не менять без PR в `lib/ai/types.ts` (Z6).
- Правка промпта меняет его версию → кэш ИИ для шага сбрасывается сам.
- Проверка качества: `eval/` (I11), прогон персонажей (I15).
