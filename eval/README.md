# eval — проверка качества без голоса

- `personas/*.md` — вымышленные рассказчики (биография по 8 блокам + манера речи + ключевые факты). Все совпадения случайны.
- `behaviors.md` — профили поведения для пограничных случаев (ключи используются в `persona_reply` и симуляторе).
- Симулятор `npm run sim -- --persona kim [--behavior wanders]` — задача I15. Оценка качества и отчёт в PR — I11.
- Отчёты прогонов пишутся в `eval/reports/` (в git не попадают).

Формат персонажа — см. `personas/kim.md`. Раздел «Ключевые факты» — эталон: симулятор сверяет с ним главы и считает потерянные или искажённые факты.
