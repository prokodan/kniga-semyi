## Цель
Родственник за 2 минуты с телефона создаёт книгу, добавляет рассказчика, записывает голосовое согласие и первую историю. Вход потом — по ссылке с токеном, без регистрации.

**Исполнитель:** Codex / Влад · **Зона:** Z1 · **Оценка:** 5 ч · **Когда:** пн 23.11

## Файлы
```
app/(family)/start/page.tsx              — создать книгу: название, рассказчик (имя, годы, фото), дата вручения
app/(family)/f/[token]/page.tsx          — главная семьи: рассказчик, прогресс «3 из 8», «записать»
app/(family)/record/[token]/page.tsx     — экран записи по вопросам
app/(family)/consent/[token]/page.tsx    — голосовое согласие (текст + запись)
components/recorder/*                    — Recorder, хук useRecorder, выбор mime, таймер, загрузка
app/api/families/route.ts                — POST: семья + рассказчик (+ фото в bucket photos)
app/api/upload-url/route.ts              — POST: подписанная ссылка на загрузку в Storage
app/api/stories/route.ts                 — POST: строка stories со status 'uploaded'
lib/db/access.ts                         — НОВЫЙ: getFamilyByToken(token) (согласовано с Z6)
```

## Что прочитать
- AGENTS.md, `lib/types/index.ts`, `lib/db/index.ts`, `content/questions/*`, токены в `app/globals.css`
- docs/ARCHITECTURE.md → «Поток данных» (аудио напрямую в Storage)

## Критерии приёмки
- [ ] Создание семьи и рассказчика с фото ≤ 2 минут на телефоне; после — ссылка `/f/<access_token>` и кнопка «скопировать / отправить»
- [ ] Голосовое согласие обязательно до первой записи: аудио в bucket `audio`, `storytellers.consent_audio_url` + `consent_at`. Текст согласия содержит фразу, что запись обрабатывают внешние ИИ-сервисы
- [ ] Запись: `MediaRecorder` с выбором формата (`audio/mp4` в Safari, `audio/webm;codecs=opus` в Chrome), лимит 5 минут, таймер, пауза/стоп, прослушать перед отправкой
- [ ] Загрузка напрямую в Storage по подписанной ссылке (не через тело функции Vercel), затем `stories` со status `uploaded`, `question_id`, `block`, `duration_sec`
- [ ] Запасной путь: загрузка аудиофайла из галереи / диктофона
- [ ] Вопрос показывается крупно (`text-elder`) и озвучивается голосом браузера (`speechSynthesis`, ru-RU), кнопки «пропустить» и «вернуться позже»
- [ ] Прогресс по блокам «3 из 8»
- [ ] Проверено руками: iPhone Safari, Android Chrome, планшет. Блокировка экрана / сворачивание не теряет запись молча (сообщение и возможность сохранить то, что есть)
- [ ] Неверный токен → понятная страница, не 500
- [ ] Работает в `AI_MODE=mock`; `npm run check` зелёный

## Чего не трогать
- Конвейер ИИ (I2) — только создать строку `stories` и вызвать `POST /api/stories/[id]/process`, когда он появится
- Миграции, `lib/types` — если не хватает поля, напиши в PR
