## Цель
Волонтёр без обучения записывает старейшину в центре за 15 минут на планшете.

**Исполнитель:** Codex / Влад · **Зона:** Z5 · **Оценка:** 4–5 ч · **Когда:** пн 23.11 (на компонентах I1)

## Файлы
```
app/kiosk/page.tsx                 — вход по PIN (KIOSK_PIN, проверка на сервере, cookie на день)
app/kiosk/new/page.tsx             — карточка старейшины (имя, годы, фото с камеры планшета)
app/kiosk/session/[id]/page.tsx    — согласие + запись по вопросам крупно
app/kiosk/queue/page.tsx           — очередь дня
app/api/kiosk/*                    — серверные ручки киоска
components/kiosk/*
```
Переиспользовать `components/recorder/*` из I1 без копирования.

## Что прочитать
- AGENTS.md, компоненты I1, `content/questions/*`, токены `text-kiosk`

## Критерии приёмки
- [ ] PIN проверяется на сервере (`KIOSK_PIN`), неверный PIN — без подсказок; выход по кнопке
- [ ] Новая карточка создаёт `families` с `source = 'kiosk'` и `storytellers`; волонтёр выбирается из `kiosk_volunteers`
- [ ] Голосовое согласие обязательно; отдельная галочка семьи «передать в архив АКНЦ» → `archive_consent`
- [ ] Запись по вопросам: текст `text-kiosk`, кнопки ≥ 64 px, «пропустить», «вернуться позже», озвучка вопроса
- [ ] Сессия `sessions.mode = 'kiosk'` с `volunteer_id`
- [ ] Очередь дня: старейшины за сегодня, статусы историй
- [ ] Ландшафтный планшет, никакой прокрутки на экране записи
- [ ] Прогон: человек, не видевший интерфейс, проводит запись за ≤ 15 минут
- [ ] `npm run check` зелёный
