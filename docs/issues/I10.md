## Цель
Главное отличие от конкурентов: после каждого ответа агент проверяет, прозвучали ли «кто, когда, где, что, живая деталь», и задаёт до 3 тёплых уточнений про конкретный пробел — без давления.

**Исполнитель:** Claude Code / Данил · **Зона:** Z2 · **Оценка:** 4–5 ч · **Когда:** пн 23.11

## Файлы
```
lib/interview/index.ts               — startSession, submitAnswer(sessionId, {text | storyId}), skip, later
lib/interview/policy.ts              — правила: ≤ 3 уточнений, пропуск, offTopicBlock, закрытие блока
```

## Критерии приёмки
- [ ] Ответ текстом или `storyId` (берётся `transcript` после шага transcribe I2) → `ai.run('completeness')`
- [ ] Неполный ответ → до 3 уточнений на вопрос, каждое про один пробел; ответы на уточнения сохраняются в `stories.followups`
- [ ] «Пропустить» и «вернуться позже» без уточнений; `refuses` → сразу дальше
- [ ] `offTopicBlock` засчитывает рассказ в подходящий блок (`stories.block`), не теряет его
- [ ] Минимум собран → `ai.run('next_question')` из банка с фразой-связкой; блок закрыт по всем вопросам → `blockDone` и предложение собрать главу
- [ ] Состояние в `sessions.state`; одинаково работает для семьи и киоска (`mode`)
- [ ] Тесты на 7 профилей из `eval/behaviors.md` в mock
- [ ] `npm run check` зелёный
