## Цель
Демо на сцене не падает ни при каком сценарии: Wi-Fi, лимит ИИ, медленный ответ.

**Исполнитель:** Claude Code / Данил · **Зона:** Z6 · **Оценка:** 2 ч · **Когда:** ср 25.11 до 14:00

## Файлы
```
scripts/seed-demo.ts         — npm run seed:demo: пересоздать демо-семью (is_demo) с историями, главами, книгой
fixtures/demo/*              — тексты и метаданные демо-историй (аудио — в Storage)
lib/stage.ts                 — withStageFallback(storyId, step, fn): STAGE_MODE + 20 с → готовый результат
app/admin/page.tsx           — кнопка «сбросить демо» (ADMIN_PIN)
.env.example                 — добавить STAGE_MODE
```

## Критерии приёмки
- [ ] `npm run seed:demo` (локально с ключами прода и в Actions вручную) за < 1 мин пересоздаёт демо-семью: рассказчик, 5+ реальных историй с согласием, готовые главы, книга PDF
- [ ] `STAGE_MODE=1`: если шаг ИИ не ответил за 20 с — показывается заранее сгенерированный результат этой демо-истории; в логах пометка
- [ ] Кнопка «сбросить демо» в админке
- [ ] Ссылка и QR демо-семьи стабильны после сброса (фиксированный `access_token`)
- [ ] Прогон без сети на стороне ИИ (неверный ключ) — демо проходит целиком
- [ ] `npm run check` зелёный
