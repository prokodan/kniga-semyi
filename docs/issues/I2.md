## Цель
Загруженная история за < 60 с превращается в главу: текст RU без переписывания голоса, заголовок, цитата, перевод на корейский, факты для карты жизни. Сбои не теряют работу и не стоят повторных денег.

**Исполнитель:** Claude Code / Данил · **Зона:** Z2 · **Оценка:** 5–6 ч (роутер уже в W0) · **Когда:** пн 23.11

## Файлы
```
lib/pipeline/index.ts            — processStory(storyId), runStep(storyId, step)
lib/pipeline/steps/*.ts          — transcribe, edit, translate (одинаковая сигнатура)
lib/pipeline/*.test.ts           — тесты в AI_MODE=mock на MemoryStore / фейковой базе
app/api/stories/[id]/process/route.ts   — POST: запустить или продолжить конвейер

lib/ai/*  (кроме index.ts, types.ts)    — правки роутера, если понадобятся
```

## Критерии приёмки
- [ ] Статусы `uploaded → transcribing → editing → translating → ready`; ошибка → `failed` + понятная причина в `stories.error`
- [ ] Каждый шаг — отдельный HTTP-вызов (укладывается в лимит функции 60 с); шаг перезапускаемый: уже сохранённые результаты не пересчитываются
- [ ] Аудио для расшифровки берётся из Storage по подписанной ссылке / скачиванием на сервере
- [ ] Сохраняются `transcript`, `text_ru`, `title`, `quote`, `facts`, `text_ko`, `title_ko`, `quote_ko`; расход пишется в `ai_usage` с `story_id`
- [ ] `AiUnavailableError` → история не падает: статус остаётся на шаге, ответ API `{ queued: true, retryInMinutes }`, экран показывает «глава будет готова через N минут»
- [ ] С ключом Gemini: история 5 минут проходит < 60 с (замер в PR)
- [ ] Тесты: полный проход в mock, перезапуск с середины, failed с причиной
- [ ] `npm run check` зелёный
