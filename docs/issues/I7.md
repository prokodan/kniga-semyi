## Цель
Комиссия видит модель монетизации в действии: выбор продукта по ценам из финмодели → «оплачено (демо)» → допы.

**Исполнитель:** Codex / Влад · **Зона:** Z4 · **Оценка:** 2–3 ч · **Когда:** вт 24.11

## Файлы
```
app/(family)/checkout/[token]/page.tsx   — выбор: цифровая книга / печать, допы
app/(family)/extras/[token]/page.tsx     — экран допов после оплаты (сказка и др.)
app/api/checkout/route.ts                — POST по токену → createDemoPayments(save в demo_orders)
lib/payments/index.ts                    — ТОЛЬКО цены PRICES_KZT / EXTRAS_KZT из финмодели
```

## Что прочитать
- `lib/payments/index.ts`, `lib/types` → `DemoOrder`, финмодель питча (цены)

## Критерии приёмки
- [ ] Цены в `PRICES_KZT` / `EXTRAS_KZT` совпадают с финмоделью и слайдами (один источник)
- [ ] Заказ пишется в `demo_orders` со статусом `paid_demo`; повторное нажатие не создаёт дубль
- [ ] На всех экранах ясно, что это демо: «оплачено (демо)», никаких полей карты
- [ ] После оплаты — экран допов со сказкой (I8) и «скоро»-карточками (видео, древо)
- [ ] Весь путь от главы до допов без ошибок на телефоне
- [ ] `npm run check` зелёный

## Чего не трогать
- Интерфейс `PaymentPort` (Z6)
