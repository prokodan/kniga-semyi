## Цель
Центр видит ценность для общины: сколько старейшин записано, сколько минут голоса сохранено, статусы книг, архив с согласием.

**Исполнитель:** Codex / Влад · **Зона:** Z5 · **Оценка:** 2–3 ч · **Когда:** вт 24.11

## Файлы
```
app/center/page.tsx            — вход по ADMIN_PIN, счётчики
app/center/families/page.tsx   — список семей и историй, статусы книг
app/center/volunteers/page.tsx — список и добавление волонтёров (kiosk_volunteers)
app/api/center/*               — серверные выборки
components/center/*
```

## Критерии приёмки
- [ ] PIN проверяется на сервере (`ADMIN_PIN`)
- [ ] Счётчики: семьи, старейшины, истории, минуты записи (сумма `duration_sec`), книги по статусам, за сегодня / всего
- [ ] Список семей: источник (семья / киоск), рассказчики, число историй, статус книги
- [ ] Раздел «Архив АКНЦ» показывает только семьи с `archive_consent = true`
- [ ] Добавление и отключение волонтёров
- [ ] Демо-семьи (`is_demo`) можно скрыть фильтром
- [ ] `npm run check` зелёный

**Если не успеваем:** только счётчики.
