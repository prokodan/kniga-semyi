## Цель
Доп, который трогает комиссию: короткая сказка по реальным историям деда с иллюстрациями, страница-книжка.

**Исполнитель:** Codex / Влад · **Зона:** Z4 · **Оценка:** 4–5 ч · **Когда:** вт 24.11

## Файлы
```
lib/tale/*                              — createTale(familyId): ai.run('tale') → ai.run('illustrate') × 3–4
app/api/extras/tale/route.ts            — POST по токену; GET статус
app/(family)/extras/[token]/tale/page.tsx — страница-книжка (листание)
components/tale/*
```

## Что прочитать
- `lib/ai/types.ts` → `tale`, `illustrate`; `prompts/tale.md`; `lib/types` → `Extra`

## Критерии приёмки
- [ ] Сказка строится по 2–5 готовым историям семьи; результат в `extras` (`type = 'tale'`), картинки в bucket `illustrations`
- [ ] Единый стиль: одна строка `style` на все картинки (акварель, простые добрые лица, без текста на картинке)
- [ ] Картинки генерируются параллельно; общий путь ≤ 2 минут; прогресс на экране
- [ ] Нет искажённых лиц на демо-семье (проверено глазами, неудачную картинку можно перегенерировать — `noCache`)
- [ ] Страница-книжка: листание свайпом, крупный текст
- [ ] В `AI_MODE=mock` — сказка из `fixtures/ai/tale.json` и SVG-плейсхолдеры
- [ ] `npm run check` зелёный

**Если не успеваем:** сказка без картинок.
