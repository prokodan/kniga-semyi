## Цель
Проверять интервью-агента, конвейер и книгу на тексте до распознавания речи: LLM играет вымышленного рассказчика, агент задаёт вопросы и уточнения, на выходе — главы, PDF и отчёт о потерянных фактах.

**Исполнитель:** Codex / Влад · **Зона:** Z2 · **Оценка:** 2–3 ч · **Когда:** пн 23.11

## Файлы
```
scripts/sim.ts           — CLI: --persona kim|pak|tsoi, --behavior <ключ>, --questions N, --pdf
eval/sim/*.ts            — загрузка персонажа, цикл интервью, сверка фактов, отчёт
package.json             — скрипт "sim" и devDependency tsx (согласовать с Z6)
```

## Что прочитать
- `eval/README.md`, `eval/personas/kim.md` (формат), `eval/behaviors.md`, `prompts/persona_reply.md`
- `lib/ai/types.ts` → `persona_reply`, `completeness`, `next_question`, `edit`, `translate`

## Критерии приёмки
- [ ] `npm run sim -- --persona kim` проходит интервью: ответы персонажа (`persona_reply`) → проверка полноты и уточнения (интервью-агент I10, до его готовности — напрямую `ai.run('completeness')`) → главы (`edit` + `translate`)
- [ ] `--behavior` переопределяет профиль персонажа; все 7 профилей запускаются
- [ ] Отчёт `eval/reports/<persona>-<дата>.md`: диалог, число уточнений по вопросам, главы RU/KR, «Ключевые факты» — найдены / потеряны / искажены
- [ ] `--pdf` собирает книгу через I5, когда он готов
- [ ] Работает в `AI_MODE=mock` и с `GEMINI_API_KEY` (локально, ключ из своего .env.local)
- [ ] `npm run check` зелёный
