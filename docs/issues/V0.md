## Цель
Интервью и киоск задают тёплые, конкретные вопросы по карте жизни, а интервью-агент знает, что должно прозвучать в ответе на каждый.

**Исполнитель:** Влад (без агента) · **Зона:** Z1 · **Оценка:** 3–4 ч · **Когда:** сб 21.11 – вс 22.11

## Файлы
```
content/questions/bank.ts      — заменить заглушку на полный банк
content/questions/blocks.ts    — только названия блоков RU/KR (ключи не менять)
```

## Что прочитать
- `lib/types/index.ts` → `Question`, `LIFE_BLOCKS`
- `content/questions/bank.ts` (формат и 8 примеров), `prompts/completeness.md`
- `eval/personas/*.md` — какие темы реально всплывают у старших

## Критерии приёмки
- [ ] 40 вопросов: ровно 5 в каждом из 8 блоков, `id` вида `childhood-03`, порядок внутри блока = порядок показа
- [ ] У каждого вопроса `ru` и `ko` (вежливая форма, понятная пожилому человеку), без канцелярита
- [ ] У каждого `minimum` из 2–5 пунктов простыми словами («кто», «где», «живая деталь или чувство» и т. п.)
- [ ] Первый вопрос каждого блока — лёгкий, тяжёлые темы (`hardship`) — не первыми
- [ ] В блоке `traditions` есть вопросы про корё мар, еду и праздники; в `legacy` — «Слова деда»
- [ ] `npm run check` зелёный (тест структуры банка)

## Чего не трогать
- Ключи блоков в `LIFE_BLOCKS`, тип `Question`
