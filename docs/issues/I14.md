## Цель
Видеть расход и квоты ИИ и переключать провайдеров без деплоя — переезд на платное = смена порядка в `ai_routes`.

**Исполнитель:** Codex / Влад (первый кандидат на передачу от Данила) · **Зона:** Z6 · **Оценка:** 3–4 ч · **Когда:** вт 24.11

## Файлы
```
app/admin/ai/page.tsx         — вход по ADMIN_PIN, дашборд
app/admin/ai/actions.ts       — server actions: обновить ai_routes / ai_providers
app/api/admin/ai/*            — выборки по ai_usage
components/admin/*
```

## Что прочитать
- docs/ARCHITECTURE.md → «Роутер ИИ», `lib/ai/config.ts`, `lib/ai/store.ts`, таблицы `ai_*` в миграции

## Критерии приёмки
- [ ] PIN на сервере (`ADMIN_PIN`), cookie
- [ ] Расход за сегодня и за месяц по провайдерам ($), процент бесплатной квоты по каждой модели (сутки Gemini — по Тихоокеанскому времени, как в роутере), доля кэша
- [ ] Последние 20 ошибок (шаг, провайдер, модель, статус, текст, время), модели на «остывании»
- [ ] Переключатели: выключить провайдера; закрепить провайдера за шагом; порядок провайдеров шага; `daily_limit`, `threshold`, бюджеты дня/месяца
- [ ] Изменения применяются со следующего вызова без деплоя
- [ ] `npm run check` зелёный

**Если не успеваем:** только чтение; переключение — правкой `ai_routes` в Supabase.

## Чего не трогать
- Логику роутера (`lib/ai/router.ts`) — только данные в таблицах
