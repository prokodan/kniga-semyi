## Цель
Споры «стало лучше или хуже» решаются цифрами: прогон персонажей даёт оценку голоса, потерянные факты и число уточнений, а при правке промптов — комментарий в PR.

**Исполнитель:** Влад + Gemini · **Зона:** Z2 · **Оценка:** 2–3 ч · **Когда:** вт 24.11

## Файлы
```
scripts/eval.ts                 — npm run eval: прогон всех персонажей через симулятор (I15) → метрики
eval/judge.md                   — промпт LLM-судьи: сохранён ли голос, 1–5
eval/README.md                  — как читать отчёт
.github/workflows/eval.yml      — на PR с изменениями prompts/** → комментарий с таблицей (согласовать с Z6)
```

## Критерии приёмки
- [ ] `npm run eval` прогоняет 3 персонажа × выбранные профили, пишет `eval/reports/<дата>.md`
- [ ] Метрики: потерянные и искажённые факты против «Ключевых фактов», среднее число уточнений, оценка голоса 1–5 (LLM-судья), время шага
- [ ] Цель MLP видна в отчёте: средняя оценка ≥ 4 из 5
- [ ] Workflow на PR с `prompts/**` оставляет комментарий с таблицей «до / после»; уважает бесплатную квоту (ограничение числа вызовов)
- [ ] Без ключей — работает в mock и честно пишет «mock, оценка не показательна»
