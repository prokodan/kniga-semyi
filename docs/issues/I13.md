## Критерии приёмки
- [ ] `npm run e2e` проходит локально в `AI_MODE=mock` на трёх профилях устройств
- [ ] Микрофон в тестах — загрузка файла (запись через MediaRecorder проверяется вручную)
- [ ] Job `e2e` в CI на PR в main; падение — скриншот и трейс в артефактах
- [ ] Время прогона < 5 минут
