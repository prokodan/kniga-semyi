## Цель
Бесплатная глава — главный «вау» для семьи и комиссии: разворот RU | KR с фото и цитатой, QR, по которому с телефона слышен живой голос рассказчика.

**Исполнитель:** Claude Code / Данил · **Зона:** Z3 · **Оценка:** 4–5 ч · **Когда:** вт 24.11

## Файлы
```
app/(family)/chapter/[storyId]/page.tsx   — разворот главы (доступ по токену семьи)
app/listen/[storyId]/page.tsx             — публичная страница голоса (по подписи в QR)
components/chapter/*                      — Spread, Quote, QrCode, ShareButton
lib/book/qr.ts                            — подпись ссылки listen (HMAC), генерация QR (SVG)
```
Зависимость `qrcode` — добавить в PR, отметить Z6.

## Что прочитать
- `lib/types/index.ts` → `Story`, токены `app/globals.css`, docs/PRODUCT.md → «Бесплатная глава»

## Критерии приёмки
- [ ] На планшете и десктопе — разворот: слева RU, справа KR; на телефоне — переключатель RU / KR
- [ ] Фото рассказчика, заголовок, цитата крупно, текст главы; корейский шрифт отображается без «квадратиков»
- [ ] QR ведёт на `/listen/<storyId>?s=<подпись>`: работает без токена семьи, открывает только эту историю; неверная подпись → 404
- [ ] Страница голоса: фото, имя, заголовок, плеер (аудио по подписанной ссылке Storage), цитата RU/KR; грузится < 2 с на мобильном интернете
- [ ] «Отправить семье» — Web Share API, запасной вариант — копирование ссылки / WhatsApp / Telegram
- [ ] Проверено: QR со слайда сканируется камерой iPhone и Android и воспроизводит голос
- [ ] Пока история не `ready` — экран ожидания со статусом конвейера
- [ ] `npm run check` зелёный
