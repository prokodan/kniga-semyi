## Цель
Из 5+ готовых глав собирается PDF, который выглядит как настоящая книга, — главный артефакт демо.

**Исполнитель:** Claude Code / Данил · **Зона:** Z3 · **Оценка:** 6–7 ч · **Когда:** вт 24.11

## Файлы
```
lib/book/pdf/*                         — документ, страницы, стили, регистрация шрифтов
lib/book/build.ts                      — buildBook(familyId): сбор глав → PDF → bucket books → books.status
app/api/books/[familyId]/build/route.ts — POST: собрать (по токену семьи)
app/book/[token]/page.tsx              — экран книги: статус, «скачать PDF», «пересобрать»
public/fonts/                          — подмножества Noto Serif / Noto Serif KR (OFL)
```
Библиотека — `@react-pdf/renderer` (или обосновать другую в PR), добавить зависимость, отметить Z6.

## Что прочитать
- docs/PRODUCT.md → «Черновик и книга», `lib/types` → `Story`, `Book`, `lib/book/qr.ts` (I3)

## Критерии приёмки
- [ ] **Первый час:** тестовый PDF с корейским текстом без «квадратиков» и с приемлемым размером (подмножество шрифта)
- [ ] Формат A5, поля под печать, номера страниц, колонтитул с названием книги
- [ ] Обложка (название, рассказчик, годы, фото), оглавление по блокам карты жизни, главы RU + KR, цитаты, QR на голос у каждой главы
- [ ] Блок `legacy` — отдельный раздел «Слова деда» / «Слова бабушки» в конце
- [ ] PDF сохраняется в bucket `books`, `books.status` `building → ready` (или `failed` + `error`), `page_count`
- [ ] Сборка 5+ глав укладывается в лимит функции (замер в PR)
- [ ] Демо-PDF приложен к PR (скрин 3 разворотов)
- [ ] `npm run check` зелёный
