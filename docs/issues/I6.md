## Цель
Семья исправляет ошибки ИИ в именах и датах до сборки книги; корейская версия обновляется сама.

**Исполнитель:** Codex / Влад · **Зона:** Z3 · **Оценка:** 2–3 ч · **Когда:** вт 24.11

## Файлы
```
app/(family)/draft/[storyId]/page.tsx  — редактор: заголовок, цитата, текст RU
app/api/stories/[id]/edit/route.ts     — PATCH по токену семьи → сохранить → перезапустить шаг translate
components/draft/*
```

## Что прочитать
- `lib/pipeline/index.ts` (I2) → `runStep(storyId, 'translate')`, `lib/types` → `Story`

## Критерии приёмки
- [ ] Редактируются `title`, `quote`, `text_ru`; сохранение по кнопке, с подтверждением
- [ ] После сохранения перезапускается только перевод (через `runStep` из I2), `text_ko`/`title_ko`/`quote_ko` обновляются; на экране статус «обновляем перевод»
- [ ] Цитата должна оставаться фразой из текста — предупреждение, если её нет в `text_ru`
- [ ] Удобно на телефоне; изменения видны в главе (I3) и в книге при пересборке (I5)
- [ ] `npm run check` зелёный

**Если не успеваем:** правка только текста RU без пересборки перевода.

## Чего не трогать
- Конвейер (I2) — только вызов `runStep`

I2, I3
