## Цель
Проверить голосом то, что текстовый симулятор не ловит: формат аудио, шум, акцент, длинные паузы, обрыв записи — на тех же устройствах, что будут на сцене.

**Исполнитель:** Влад + Данил · **Зона:** Z1 · **Оценка:** 2–3 ч · **Когда:** ср 25.11 (можно раньше, как только I1 на проде)

## Файлы
```
eval/voice-runs.md     — НОВЫЙ: журнал прогонов (устройство, персонаж, профиль, время, результат, баги)
```
Аудио в репозиторий не кладём — оно уходит в Storage через само приложение.

## Критерии приёмки
- [ ] Каждый из 3 персонажей надиктован через прод: iPhone Safari, Android Chrome, планшет
- [ ] Покрыты профили: `one-word`, `wanders`, `koryo-mar`, `long` (до 5 мин), `emotional`; плюс блокировка экрана во время записи и запись при плохой сети
- [ ] Для каждого прогона: время до готовой главы, качество расшифровки (имена, корё мар), уточнения агента
- [ ] Все баги — issues с меткой `bug` и ссылкой на строку журнала
- [ ] Синтез речи не используется — только живые голоса
