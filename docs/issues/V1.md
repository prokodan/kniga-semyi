## Критерии приёмки
- [ ] Схема JSON в конце каждого промпта не изменена (её проверяет `lib/ai/types.ts`)
- [ ] `edit`: не придумывает факты, сохраняет обороты и слова корё мар; цитата — дословно из текста
- [ ] `completeness`: одно уточнение за раз, на «вы», про самый важный пробел; на `refuses` и `emotional` — без давления
- [ ] Прогон симулятора (I15) по 3 персонажам: оценка голоса ≥ 4 из 5 на вашем наборе, потерянных ключевых фактов ≤ 1 на персонажа
- [ ] Изменения и результаты прогона — в описании PR
