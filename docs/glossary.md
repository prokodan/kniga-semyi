# Глоссарий: корё мар и реалии → 한국어

Для переводчика (`prompts/translate.ko.md`), проверяющего и автопроверки `npx tsx scripts/kr-check.ts`.
Автопроверка читает таблицы ниже: если русское слово есть в главе, в корейском тексте должен быть
один из вариантов из колонки «한국어». Поэтому формат строгий.

**Как читать колонки**
- **RU** — варианты написания через ` / `. `*` в конце — «слово начинается так» (`колхоз*` = колхоз, колхозе, колхозники);
  без `*` — слово целиком.
- **한국어** — допустимые эквиваленты через ` / `. Скобки — пояснение, при сверке не учитываются: `한식(寒食)` = `한식`.
- Регистр: в разделах «Топонимы» и «Корейские фамилии» слово сверяется с заглавной буквы (в «дальнем углу» — не топоним),
  в остальных — без учёта регистра.
- **Пояснение** — для человека. `не: 아버님 / 아빠` в этой колонке — варианты, которых в главе быть не должно
  (автопроверка даёт флажок `glossary:variant`, если русское слово есть, а в корейском встретился такой вариант).
- **Носитель** — ❓ = эквивалент предложен, но не подтверждён носителем; ✓ = подтверждён. Пока ✓ ставит только носитель.

**Правила перевода** (то, что не сводится к одному слову)
- **Своих пояснений не добавляем** — ни в скобках, ни через тире: 아파디 우리(아버지의 집), 아지바이(아버지) — ошибка.
  Скобки допустимы, только если они есть в оригинале, для пояснения реалии ниже (콜호스(집단농장)) и для ханча (한식(寒食)).
  Автопроверка: флажок `paren` (🔴).
- Пояснение в скобках из русского текста («аппади (отец)») в корейском не повторяем — эквивалент уже понятен.
- Корё мар — ровно эквивалентом из таблицы, не транслитерацией (не 아파디, 아지바이).
- Одно имя — одно написание во всей главе (Лена → 레나, не 렌나 рядом с 레나).
- Смысл связей сохраняем: желание ≠ факт («чтобы хоть немного язык знать» ≠ «язык немного узнали»),
  «в Талдыкоргане» (где) ≠ «из Талдыкоргана» (откуда родом).
- Советские реалии при первом упоминании — с пояснением в скобках: 콜호스(집단농장), 솝호스(국영농장); дальше коротко.
- Повествование — 한다체 (했다, 살았다). К родителям, старшим и учителям — почтительное -시- (일하셨다, 말씀하셨다).
  Прямое обращение рассказчика к внукам — 해라체 (들어라, 잊지 마라, 기억해라, 건강하게 살아라), не 해요체: так дед / бабушка
  говорят с внуками, и это тот же простой уровень речи, что 한다체 повествования, — абзац не «скачет» (решение команды 25.11
  по норме языка, #154). Автопроверка: `style:grandkids` (🟡) — 해요체 в абзаце с обращением к внукам; `style:mixed` — по абзацам.
- «Она / он» о бабушке, дедушке, родителях, жене — не 그녀 / 그 (книжно): по имени или по роли — 할머니, 아내, 그 사람, 아버지.
- О своих родителях рассказчика — 아버지 / 어머니, не 아버님 / 어머님 (решение команды 25.11). 아버님 / 어머님 — только о чужих
  родителях, свёкре / свекрови, тесте / тёще и в вопросах к собеседнику («아버님은 어떤 분이셨어요?» в банке вопросов верно).
  Автопроверка: `glossary:variant` у аппади / омани и `style:parents` на 아버님 / 어머님 в повествовании главы.
- ㄹ-глаголы с -시-: ㄹ выпадает перед ㅅ — 썰다 → 써셨다, 만들다 → 만드셨다, 살다 → 사셨다, 놀다 → 노셨다 (не 썰으셨다, 만들으셨다).
  Исключение — ㄷ-неправильные, где ㄹ появляется из ㄷ: 듣다 → 들으셨다, 묻다 → 물으셨다, 걷다 → 걸으셨다, 싣다 → 실으셨다.
  Автопроверка: `style:rieul` (🟡).
- Годы — цифрами: «в шестьдесят третьем» → 1963년.

## Корейские фамилии

Русское написание фамилии → корейский слог. Сверяется только слово с заглавной буквы целиком.
Имя и отчество — транслитерацией: Николай Петрович → 니콜라이 페트로비치, Анна Петровна → 안나 페트로브나.
