## 3. Как работаем (обязательно для каждого агента)

**Флаги (с 27.11, #223).** Один `main` на прод, превью и staging → слияние сразу в проде. Всё новое по поведению — за флагом
`lib/flags` (по умолчанию выключен в Production, включён на превью / staging). Выкатка: превью → семьи с `families.labs` →
все (PR «включить <имя>», потом PR «убрать флаг»). Без флага: багфиксы, тексты, docs, админка / скрипты команды. До финала 6.12 —
в проде новые флаги не включать. В PR — строка `Флаг: …`, её проверяет CI; Claude продукта проверяет при ревью.

**Флаги — как пользоваться (#223).**
- **Завести:** строка в `lib/flags/registry.ts` (`имя: { description, owner, issue }`, имя `snake_case`) → в коде
  `flag("имя", { familyId: family.id, labs: family.labs })` из `lib/flags` (server-only); клиентскому компоненту —
  `flagValues(ctx)` пропсом, читать через `isFlagOn` из `lib/flags/shared`. Неизвестное имя — ошибка типов.
  В PR — `Флаг: имя`. Выключенный флаг = старое поведение без изменений (ветка `else` — то, что сейчас в проде).
- **Окружение (`FLAGS_ON`, через запятую, `*` = все):** Vercel Preview = `*`, Production — **не задавать** (= все
  выключены). Не задан локально / в тестах / в CI / на превью — включены все. Что включено — `/api/health` → `flags_on`.
- **Одной семье:** `/admin/families` → в карточке семьи кнопка «<имя> — включить семье» (пишет `families.labs`, без
  деплоя; выключить — той же кнопкой). Список флагов и «семей с флагом: N» — там же, сверху.
- **Всем:** PR «включить <имя>» — `everyone: true` в реестре (Флаг: <имя>). Потом PR «убрать флаг»: удалить строку
  реестра и ветку `if` (Флаг: не нужен — уборка флага <имя>); имя в `labs` семей можно не чистить — неизвестные игнорируются.
- **CI `flag-line`:** строка `Флаг: <имя из реестра>` или `Флаг: не нужен — <почему>` (одна); комментарии шаблона не
  считаются. Пропуск — Dependabot и PR только с `docs/**` / `*.md` в корне (`prompts/*.md` — не docs). Правка описания
  перезапускает проверку сама.

1. **Одна задача = один новый чат агента = одна ветка = PR.** Задачи — GitHub Issues. Длинные чаты сжигают лимиты.
2. Начало: `AGENTS.md` → своя issue → `docs/STATUS.md`. Больше заранее ничего не читать.
3. PR по шаблону. **Раздел «📝 Заметки для команды» обязателен** (см. п. 4).
4. **Всё, что агент хотел бы сказать человеку, пишется в репозиторий, а не только в чат:**
   - в PR → «📝 Заметки для команды»: на что обратить внимание, принятые решения, что не сделано и почему,
     что проверить руками с телефона (точные ссылки);
   - каждое «осталось / потом / нужно руками» → **сразу отдельная issue** (метки зоны; без milestone, если после
     питча) и ссылка на неё в заметках;
   - решение, влияющее на других, → строка в `docs/DECISIONS.md`.
   Финальное сообщение агента в чате = копия заметок из PR. Так любой (человек или Claude) видит всё по PR/issues,
   ничего не собирается вручную из чатов.
5. Слияние: агент **сам** сливает свой PR (squash), но только когда зелёные `ci`, `e2e` **и** `flag-line`; если PR меняет
   `prompts/` — ещё дождаться комментария `eval` (🔴 по фактам = не сливать). Слияние при красной проверке запрещено.
6. После слияния: если были миграции — дождаться `migrate`; затем `smoke`; если трогал демо — `seed-demo`.
7. Конфликт с main → влить main в ветку и разрешить; конфликт в `docs/STATUS.md` → оставить строки обеих зон.
8. Ключи, `LISTEN_SECRET`, данные демо-семьи — не трогать без явного разрешения Данила.
9. В среде агента нет ключей ИИ и доступа к базе: живые прогоны — через workflows (`sim`, `eval`, `diag`, `ai-models`,
   `smoke`, `seed-demo`) по `workflow_dispatch`; GitHub API — только REST (GraphQL недоступен).

### 5.1 Себестоимость, хранение и модель оплаты (#236, 27.11)

**Откуда цифры.** Прод 22–25.11: 6 семей без демо, 10–37 готовых глав, `ai_usage` + `storage.objects` (SQL только на чтение).
Все $ пересчитаны **по ценам 2027** (`lib/ai/config.ts`: Gemini платно, 3.6 Flash после акции $1,50 / $7,50; gpt-5-mini — по
цене gpt-5.4-mini), потому что до 25.11 Gemini был бесплатным и `cost_usd` занижен. Курс 460 ₸/$ (НБ РК 23.11 — 456,83; решение Данила 27.11: тенге нестабилен, в начале 2026 был ~500 — берём 460, цены периодически пересчитываем от $).
Факт: **$0,18 медиана / $0,25 p90 на семью** (без сказки), $0,009 на главу, перевод $0,004 на главу; аудио m4a **0,47 МБ/мин**.
Но у тестовых семей 0,6 мин аудио на главу — у настоящего старшего будет 3–4 мин, поэтому ниже — модель по минутам.

**Допущения по тарифам** (в `lib/payments` объёма нет — зафиксировать на странице оплаты): Короткая 10 глав / 30 мин,
Стандарт 25 / 90, Полная 50 / 180 (до 2 рассказчиков). Запас ×1,3 на повторы, пересборки и правки семьи.
«Обычно» — основной маршрут (Flash-Lite); «худшее» — всё ушло на резерв (3.6 Flash 2027, gpt-5.4-mini, gpt-4o-transcribe).
